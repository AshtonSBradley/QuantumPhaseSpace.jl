Distributions

The phase-space distributions that may be sampled for these quantum states are

Husimi-Q

QuantumPhaseSpace.husimiQ — Function
α,ᾱ = husimiQ(state <: State,N)

Generate N samples from the Husimi-Q phase-space distribution for state.

Moments of the Husimi-Q distribution generate quantum operator averages that are anti-normally ordered.

source

Glauber-P

QuantumPhaseSpace.glauberP — Function
α,α⁺ = glauberP(state <: State,N)

Generate N samples from the Glauber-Sudarshan-P phase-space distribution for state.

Moments of the Glauber-Sudarshan-P distribution generate quantum operator averages that are normally ordered.

source

Positive-P

QuantumPhaseSpace.positiveP — Function
α,α⁺ = positiveP([rng], state, N)

Generate N samples from the positive-P (+P) phase-space distribution for state.

Moments of the +P distribution generate quantum operator averages that are normally ordered.

The doubled coordinates α,α⁺ need not be conjugates and are generally correlated.

For Gaussian, Squeezed, SqueezedTwoMode and Bogoliubov, select method=:drummond to minimise mean-square nonconjugacy at initialisation. method=:canonical (the default for these types) uses Husimi-Q conversion. SqueezedTwoMode returns four vectors in the order (α₁, α₁⁺, α₂, α₂⁺).

source

Direct Gaussian positive-P sampling explains method=:drummond and its two-mode squeezing convention.

Wigner

QuantumPhaseSpace.wigner — Function
α,α⁺ = wigner(state <: State,N)

Generate N samples from wigner phase-space distribution for state.

Moments of the Wigner distribution generate symmetrically ordered quantum operator averages.

source
wigner([rng], state::Union{SlaterDeterminant,FermionThermal}, N; pairing=false)

Moment-matched initial ensemble for fermionic truncated Wigner. Return a complex M × M × N array ρ, where ρ[i,j,k] is a sample of cᵢ†cⱼ - δᵢⱼ/2. With pairing=true, return (; ρ, τ) with the antisymmetric pair variables τ[i,j,k] for cᵢcⱼ. The Gaussian draw matches the means and symmetrized covariances of the bilinears. For a fixed-number thermal state, first draw a Slater determinant from the canonical ensemble and apply the moment matching conditional on that determinant.

source

Positive-W

QuantumPhaseSpace.positiveW — Function
positiveW([rng], state, N)

Exact doubled positive-W sampling. Generic states add independent circular noise η=ξ/√2 to a valid positive-P pair as (α+η,αplus+conj(η)). Coordinates are generally correlated and need not be conjugates. They are not ordinary W samples and must not be projected into ordinary truncated-Wigner initial data.

Fock states use an exact binomial–Gamma radial mixture with no spatial window or asymptotic switch. method=:convolution selects the generic construction for a benchmark of the same representation and physical estimators.

source

Reproducible and multimode sampling

Every sampler accepts sampler(rng, state, N) with an explicit AbstractRNG; the original sampler(state, N) uses Random.default_rng(). The historical single-mode vectors and SqueezedTwoMode four-vector tuple are preserved. New multimode states return a pair of modes × samples matrices.

sampleQ(rng,state,N) always returns one modes × samples matrix, even for a single mode. sampleQ! fills a caller-owned matrix. Both accept zero columns. The defaults use Float64 and circular randn(rng,ComplexF64) noise with E[abs2(ξ)]=1. A trajectory's norm is never fixed to a particle count.

QuantumPhaseSpace.nmodes — Function

Number of modes. Matrix sampling uses modes × samples.

source
QuantumPhaseSpace.sampleQ — Function
sampleQ([rng], state, N; diagnostics=false, max_attempts=max(1000,1000N))

Return one complex matrix of Q coordinates, with modes in rows and samples in columns, for every state (including legacy two-mode states). With diagnostics=true, return (matrix, SamplingDiagnostics). Rejection limits apply to outer proposals; nested component samplers enforce their own limits.

source
QuantumPhaseSpace.sampleQ! — Function
sampleQ!([rng], Z, state; max_attempts=...)

Fill a caller-owned complex modes × samples matrix. Returns Z. On rejection failure the destination may contain a partial batch and a SamplingError is raised; only successful returns represent complete batches.

source
