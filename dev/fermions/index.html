Fermionic truncated Wigner

SlaterDeterminant and FermionThermal initialize the fermionic truncated Wigner approximation (fTWA). They match the exact quantum means and symmetrized covariances of the chosen bilinears. The Gaussian ansatz fixes higher moments of the sampled ensemble. In the canonical thermal case, the package draws an occupation pattern first and uses the Slater ensemble for that pattern. Davidson, Sels and Polkovnikov.

Each array has shape modes × modes × samples. The Hermitian array ρ represents cᵢ†cⱼ - δᵢⱼ/2. Read occupation in mode i as real(ρ[i,i,k]) + 1/2 on draw k. With pairing=true, the result also includes τ for cᵢcⱼ. τ is antisymmetric and its ensemble mean vanishes for the number-conserving states here. Its fluctuations include both occupied pairs and empty pairs.

using QuantumPhaseSpace, Random, Statistics

rng = MersenneTwister(136)
slater = SlaterDeterminant([1, 0, 1, 0])
ρ = wigner(rng, slater, 10_000)

energies = [-1.0, -0.25, 0.25, 1.0]
thermal = FermionThermal(energies, 2.0; particles=2)
samples = wigner(rng, thermal, 10_000; pairing=true)

(; slater_occupation=mean(real.(ρ[1,1,:])) + 1/2,
   slater_hopping_variance=mean(abs2, ρ[1,2,:]),
   thermal_occupation=mean(real.(samples.ρ[1,1,:])) + 1/2)
(slater_occupation = 1.0, slater_hopping_variance = 0.4902008059051334, thermal_occupation = 0.9308000000000001)

For a Slater determinant, pass occupied orbitals as columns to sample in a different one-body basis. Pass a Hermitian one-body Hamiltonian to FermionThermal to sample in the Hamiltonian's input basis. For a mode transformation c → U*c, these conventions give ρ → conj(U)*ρ*transpose(U) and τ → U*τ*transpose(U).

QuantumPhaseSpace.SlaterDeterminant — Type
SlaterDeterminant(occupations)
SlaterDeterminant(occupied_orbitals)

A number-conserving fermionic pure state. Supply a vector of integer occupations (zero or one in the sampling basis), or an M × N matrix whose columns are orthonormal occupied orbitals in an M-mode basis. Each mode is a spin-orbital.

QuantumPhaseSpace.FermionThermal — Type
FermionThermal(energies, β; μ=nothing, particles=nothing)
FermionThermal(h, β; μ=nothing, particles=nothing)

Free-fermion thermal state at finite inverse temperature β ≥ 0. Supply one-body energies in the sampling basis or a Hermitian one-body Hamiltonian h. By default the state is grand canonical with chemical potential zero. Set μ for a different chemical potential, or set particles for the canonical ensemble at that fixed total number.
